Hermes Agent

This site describes a privately operated installation of the open-source Hermes Agent assistant. It is not the official website of Nous Research.

The application helps its account owner work with Google Workspace services, such as Google Drive, Sheets and Docs, using permissions granted through Google OAuth. It reads or changes content as needed to carry out the owner's requests. Available operations depend on the permissions granted and the APIs enabled.
